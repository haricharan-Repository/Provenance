## Story

As a signed-in shopper, I cannot use a coupon after its expiry date.

## Acceptance criteria

- AC1: Given a coupon whose expiry date was yesterday, when I apply it, then I see "This coupon has expired" and the total stays unchanged.
- AC2: Given a coupon whose expiry date is today (UTC), when I apply it, then the discount is applied.
- AC3: Given the coupon service returns an error, when I apply a coupon, then I see "Coupons are unavailable. Try again." and the total stays unchanged.
- AC4: Given a code longer than 20 characters, when I apply it, then the API rejects it with COUPON_TOO_LONG.
