## Story

As a signed-in shopper, I get the percentage discount of a valid coupon on my $100.00 cart.

## Acceptance criteria

- AC1: Given a valid 25% coupon, when I apply it, then the total becomes $75.00 and I see "Coupon applied".
- AC2: Given an unknown code, when I apply it, then I see "Coupon not found" and the total stays unchanged.
- AC3: Given an empty code, when I apply it, then the API rejects it with COUPON_REQUIRED.
